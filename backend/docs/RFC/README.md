# RFCs

Mudanças grandes (nova dependência crítica, mudança de modelo de dados central, novo provedor de IA, nova região) começam como RFC em `docs/RFC/AAAA-NN-titulo.md` com: problema, proposta, alternativas, impacto em SLO/custo/privacidade, plano de rollout e rollback. Comentários por 5 dias úteis em PR; decisão registrada como ADR (`docs/ADR/`). Templates em `docs/ADR/TEMPLATE.md` (seção Contexto/Decisão).
